## Comment s'en servir

1. **Télécharger** le notebook (bouton *Download* sur son fichier).
2. Sur Kaggle : **New Notebook** → `File → Upload Notebook`.
   *(Variante : `File → Import Notebook` et coller l'URL de ce dépôt.)*
3. **Attacher la compétition** : panneau de droite → `Add Input` → onglet **Competitions** →
   la compétition de classe. Il faut l'avoir rejointe au préalable.
   On attache **la compétition**, jamais un dataset recopié : une deuxième copie des données est
   une source de divergence garantie.
4. **`Save & Run All`** — pas `Save`. Le notebook écrit `submission.csv` dans ses sorties.

> Le détail de chaque étape est dans le wiki du cours, section 12 « Guide de démarrage ».
